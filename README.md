## Git Commands

### 1. Clone Repository

```bash
git clone https://github.com/qanh2311/React_Start0.git
```

### 2. Push Code

```bash
git add .
git commit -m "Update React learning notes"
git push origin main
```

### 3. Pull Code

```bash
git pull origin main
```

### 4. First-Time Push

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/qanh2311/React_Start0.git
git branch -M main
git push -u origin main
```
